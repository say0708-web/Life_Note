# 인생낙서교실

어르신이 질문을 따라 자신의 기억을 떠올리고, 짧은 답을 모아 자서전 글쓰기 재료로 활용할 수 있도록 만든 **기억 회상형 글쓰기 보조 앱**임.

## 1. 앱의 목적

- 강사가 모든 수강생에게 많은 질문을 직접 하기 어려운 상황을 보완함.
- 어르신이 앱의 질문을 보면서 스스로 기억을 떠올리도록 도움.
- 긴 글을 앱에서 작성하는 방식이 아니라, **한 줄의 짧은 기억**을 입력하도록 설계함.
- 마지막에는 입력한 기억을 한눈에 확인하여 워크북에서 원하는 기억을 골라 글을 확장하도록 연결함.
- 앱은 자서전 글을 대신 써주는 것이 아니라 **글쓰기 전에 기억을 꺼내고 정리하는 도구**임.

## 2. 전체 회기 구성

앱에는 2~8회기를 넣고, 1회기 '나를 알아보기'는 앱 외 강사 수업 영역으로 구성함.

- 🏡 ② 내가 자란 곳
- 🎒 ③ 학창시절
- 🌸 ④ 청춘의 기억
- 💼 ⑤ 내가 해온 일
- 👨‍👩‍👧 ⑥ 함께한 가족
- ❤️ ⑦ 내 인생의 사람들
- ✨ ⑧ 나의 인생 이야기

## 3. 기억을 꺼내는 방식

기본 기억 카드와 주제별 질문을 통해 한 번에 하나의 기억을 떠올리도록 함.

대표적인 질문 방향은 다음과 같음.

- 장소 / 어디?
- 사람 / 누구?
- 사건 / 무슨 일?
- 감각 / 무엇이 느껴졌나?
- 음식 / 무엇을 먹었나?
- 마음 / 어떤 마음?

주제에 따라 꿈, 사랑, 취미·유행, 성취, 어려움, 배움, 가족, 만남, 영향, 감사, 미래 등 주제에 맞는 질문도 사용함.

### 표시 원칙

앱의 기억 항목은 **'분류명 / 질문'** 형태로 표시함.

예:
- 장소 / 어디?
- 사람 / 누구?
- 성취 / 무엇을 이루었나?
- 꿈 / 무엇을 꿈꿨나?
- 취미·유행 / 무엇을 좋아했나?

질문 뒤에 같은 의미의 분류명을 반복하지 않도록 구성함.

## 4. 사용 흐름

1. 첫 화면에서 인생낙서교실 시작
2. ②~⑧ 중 글쓰기를 원하는 주제 선택
3. 해당 주제의 첫 질문 확인
4. 기억을 꺼낼 질문 방향 선택
5. 질문을 보고 한 줄로 기억 입력
6. 기억 저장
7. 답하기 어려운 질문은 건너뛸 수 있음
8. 여러 개의 기억을 계속 모음
9. 마지막 화면에서 모은 기억을 확인
10. 쓰고 싶은 기억을 골라 워크북에서 이야기를 확장함

## 5. 기억 지도

마지막 화면은 앱에서 입력한 짧은 기억을 모아 보여주는 영역임.

- 처음 떠올린 기억
- 질문에 대한 짧은 답
- 질문 방향별 기억

을 한눈에 확인할 수 있도록 구성함.

중요한 원칙은 **앱에서 완성된 자서전 문장을 만들어 주는 것이 아니라, 어르신이 직접 워크북에서 기억에 살을 붙이도록 돕는 것**임.

## 6. 어르신 사용성을 위한 설계

- 모바일 화면에 맞춘 세로형 UI
- 큰 글씨
- 충분한 터치 영역
- 짧고 직관적인 버튼 문구
- 미색 계열의 보조 버튼
- 포인트 색상의 주요 행동 버튼
- 카드형 질문 배치
- 질문을 모두 답하지 않아도 진행 가능
- 같은 화면에서 여러 기억을 계속 저장할 수 있도록 구성

## 7. 주요 버튼 원칙

### 상단

- `← 전 단계`
- 이전 화면으로 돌아가는 용도임.
- 작은 미색 버튼으로 표시함.

### 질문 화면

- `다음 질문으로 →`
- 현재 질문을 넘기는 용도임.

### 마지막 화면

- `← 전 단계`
- `다른 기억 꺼내기`

`다른 기억 꺼내기`를 선택하면 기존에 작성한 기억이 삭제된다는 안내 후 처음 화면으로 이동함.

## 8. 앱 제목

앱의 브랜드명은 **인생낙서교실**로 통일함.

첫 화면의 표지 이미지를 사용하며, 표지 이미지 아래에 동일한 제목을 중복 표시하지 않음.

## 10. 기술 구조

현재 버전은 별도의 서버나 AI API를 필요로 하지 않는 **HTML 기반 교육용 앱**으로 운영하는 것을 기본 방향으로 함.

기본 구성:
- HTML
- CSS
- JavaScript
- 별도 설치 없이 브라우저에서 실행

따라서 수업 현장에서 다수의 어르신이 동시에 사용하는 상황에서도 AI API 호출에 따른 비용, quota, 429 오류 등의 영향을 받지 않는 구조임.

## 11. 운영 시 주의사항

- 앱은 자서전 원고를 자동 완성하는 도구가 아님.
- 어르신의 기억을 대신 판단하거나 사실 여부를 판정하지 않음.
- 입력한 짧은 기억을 글쓰기의 출발점으로 활용함.
- 수업에서는 앱 사용 후 워크북으로 이동하여 기억에 장소, 사람, 사건, 감정, 상황 등의 내용을 덧붙이는 방식으로 운영하는 것이 적합함.
