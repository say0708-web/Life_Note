# 인생낙서교실 v48

## 1. 앱 개요

-   앱명: 인생낙서교실
-   목적: 70\~80대 어르신이 질문을 따라가며 자신의 기억을 떠올리고, 짧게
    기록하여 자서전 글쓰기의 재료를 모으도록 돕는 기억 회상·글쓰기 보조
    앱임
-   핵심 원칙: 글을 대신 써주는 앱이 아니라, 기억을 떠올릴 수 있도록
    질문을 단계적으로 제공하는 방식임
-   대상: 70\~80대 어르신
-   최우선 사용성: 큰 글자, 단순한 선택, 명확한 앞·뒤 이동, 한 화면의
    정보량 최소화임

## 2. 전체 화면 흐름

주제 선택 → ① 기억 방향 고르기 → ② 세부 기억 고르기 → ③ 질문에 답하기 →
④ 이야기 재료 보기

### 단계별 의미

1.  **① 기억 방향 고르기**
    -   장소 / 어디?
    -   사람 / 누구?
    -   사건 / 무슨 일?
    -   감각 / 무엇이 느껴졌나?
    -   음식 / 무엇을 먹었나?
    -   마음 / 어떤 마음?
2.  **② 세부 기억 고르기**
    -   선택한 기억 방향에 따라 세부 기억 항목을 보여줌
    -   예: 장소 → 옛마을·고향, 우리 집, 동네 풍경, 자주 가던 곳, 사라진
        곳, 기타
3.  **③ 질문에 답하기**
    -   선택한 세부 기억과 연결된 질문을 보여줌
    -   한 줄 정도의 짧은 답을 작성하도록 안내함
    -   `기억 저장`을 누르면 다음 질문으로 이동함
    -   `다음 질문으로`를 누르면 답을 쓰지 않고 다음 질문으로 이동할 수
        있음
    -   `← ② 세부 기억 고르기`로 바로 이전 단계로 돌아갈 수 있음
4.  **④ 이야기 재료 보기**
    -   오늘 저장한 기억을 한눈에 모아 보여줌
    -   세부주제 → 질문 → 실제 작성한 답변의 순서로 확인할 수 있음
    -   실제 작성한 기억 답변이 가장 잘 보이도록 시각적 위계를 조정함
    -   워크북에 옮겨 쓸 기억을 선택할 수 있도록 안내함

## 3. 앞·뒤 이동 원칙

`전 단계`라는 모호한 표현 대신 돌아갈 화면을 직접 표시함.

-   ① 기억 방향 고르기 → `← 주제 선택`
-   ② 세부 기억 고르기 → `← ① 기억 방향 고르기`
-   ③ 질문에 답하기 → `← ② 세부 기억 고르기`
-   ④ 이야기 재료 보기 → `← ③ 질문으로 돌아가기`

어르신이 버튼을 눌렀을 때 어디로 이동하는지 바로 이해할 수 있도록
목적지를 직접 표시하는 구조임.

## 4. 질문 진행 원칙

-   질문에는 번호를 표시하여 반복 질문이나 진행 순서를 확인하기 쉽게 함
-   기억을 저장하지 않아도 `다음 질문으로` 이동할 수 있도록 구성함
-   기억을 저장하면 다음 질문으로 자동 이동함
-   한 세부 기억의 질문을 모두 마치면 세부 기억 선택 화면으로 돌아감
-   답변을 강제로 길게 작성하도록 하지 않으며, 짧은 한 줄도 충분하다는
    안내를 유지함

## 5. 기억 지도 표시 원칙

-   `오늘 떠올린 기억`을 핵심 정보로 강조함
-   저장된 기억의 실제 답변을 가장 크게 표시함
-   세부주제와 질문은 답변을 이해하기 위한 보조 정보로 배치함
-   기억 카드 사이의 간격과 줄간격을 줄여 전체 화면의 세로 길이를 조정함
-   워크북 안내 문구는 기억 내용보다 작게 표시함
-   중복되는 안내 문구는 제거함

## 6. 70\~80대 사용자를 위한 UX 기준

-   한 화면에 너무 많은 선택지를 동시에 보여주지 않음
-   기억 방향과 세부 기억을 별도 단계로 분리함
-   버튼의 목적지를 명확하게 표시함
-   아이콘과 짧은 문구를 함께 사용하여 의미를 빠르게 파악할 수 있도록 함
-   지나치게 작은 글자는 피하고, 세로 공간을 줄일 때도 읽기 가능성을
    우선함
-   화면마다 사용자가 해야 할 행동을 단순하게 유지함
-   앞뒤 이동에서 현재 위치를 잃지 않도록 단계 번호를 일관되게 표시함

## 7. 현재 버전

-   기준 버전: **v48**
-   v48 주요 수정:
    -   `오늘 떠올린 기억` 영역의 세로 크기 축소
    -   제목 및 설명 줄간격 축소
    -   기억 카드의 상하 여백 축소
    -   전체 화면 밀도 소폭 조정
    -   워크북 안내 영역 축소
    -   내용 및 기능은 변경하지 않고 가독성과 화면 효율만 조정함

## 8. 버전 관리 원칙

-   이후 수정본은 v49, v50, v51 순으로 증가시킴
-   수정 요청이 없는 기능·내용·디자인은 임의로 변경하지 않음
-   수정할 때마다 앞·뒤 이동 연결성을 함께 확인함
-   단계 번호와 버튼 문구가 실제 화면의 단계와 일치하는지 확인함
-   70\~80대 사용자가 실제로 이해할 수 있는지 기준으로 화면을 검토함

## 9. 핵심 검수 체크리스트

### 화면 연결

-   [ ] 주제 선택 → ① 기억 방향 고르기
-   [ ] ① → ② 세부 기억 고르기
-   [ ] ② → ③ 질문에 답하기
-   [ ] ③ → ④ 이야기 재료 보기
-   [ ] 각 단계의 뒤로가기가 바로 이전 화면으로 이동하는지 확인

### 질문

-   [ ] 질문 번호가 순서대로 표시되는지 확인
-   [ ] 답변 없이 다음 질문으로 이동 가능한지 확인
-   [ ] 기억 저장 후 다음 질문으로 이동하는지 확인
-   [ ] 마지막 질문 후 세부 기억 선택으로 돌아가는지 확인

### 기억 지도

-   [ ] 저장한 기억이 실제 답변과 함께 표시되는지 확인
-   [ ] 답변 내용이 가장 잘 보이는지 확인
-   [ ] 워크북 안내가 기억 내용보다 과도하게 크지 않은지 확인

### 어르신 사용성

-   [ ] 글자가 충분히 읽기 쉬운지 확인
-   [ ] 버튼의 목적지를 바로 이해할 수 있는지 확인
-   [ ] 한 화면의 정보량이 과도하지 않은지 확인
-   [ ] 앞뒤 이동에서 현재 위치를 잃지 않는지 확인
