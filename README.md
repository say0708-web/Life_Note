# 인생낙서교실 v55

## 1. 버전 기준

- 기준 원본: **v48**
- 현재 버전: **v55**
- v48 이후 요청된 이미지 교체 사항을 순차적으로 반영한 버전임
- 기존 앱의 내용·기능·화면 연결 구조는 임의로 변경하지 않는 것을 원칙으로 함

## 2. 이번 버전(v55) 변경사항

- **⑧ 나의 인생 이야기** 페이지의 상단 이미지를 새로운 3:1 이미지로 교체함
- 기존 이미지 영역의 크기·위치·비율을 유지함
- 이미지 파일을 HTML 내부에 포함하여 별도 이미지 파일 없이 실행 가능하도록 구성함

## 3. 현재 이미지 교체 현황

다음 주제의 상단 이미지가 교체된 상태임.

1. **② 내가 자란 곳**
2. **③ 학창시절**
3. **④ 청춘의 기억**
4. **⑤ 내가 해온 일**
5. **⑥ 함께한 가족**
6. **⑦ 내 인생의 사람들**
7. **⑧ 나의 인생 이야기**

## 4. 이미지 제작 기준

- 이미지 비율: **3:1**
- 앱의 기존 이미지 영역에 맞춰 표시함
- 6개 이상의 주제 이미지가 동일한 그림체·색감·분위기를 유지하도록 제작하는 것을 기준으로 함
- 이미지 교체 시 기존 화면 구성과 질문 내용은 변경하지 않음

## 5. 앱 운영 원칙

- 대상: **70~80대 어르신**
- 사용자가 복잡한 화면을 거치지 않고 기억을 쉽게 떠올릴 수 있도록 구성함
- 주제 선택 → 세부 기억 선택 → 질문에 답하기 → 이야기 재료 보기의 흐름을 유지함
- 앞뒤 화면 이동이 명확하게 연결되도록 구성함
- 버튼 문구는 어르신이 기능을 직관적으로 이해할 수 있도록 작성함
- 불필요한 입력 단계와 중복 페이지는 최소화하는 방향임

## 6. 수정 시 주의사항

- **v55를 이후 이미지 교체 작업의 직접 기준 파일로 사용함**
- 요청하지 않은 질문, 문구, 기능, 디자인, 화면 연결은 변경하지 않음
- 이미지 교체 작업은 해당 주제의 이미지 영역만 수정함
- 수정 시 버전 번호를 **v56, v57, v58...** 순서로 증가시킴
- 수정본 파일명에도 동일한 버전 번호를 사용함

## 7. 저작권 및 제작 안내

- 본 앱은 기억 회상과 이야기 작성을 돕는 교육용 앱임
- 앱의 저작권 안내 문구 및 제작 관련 표기는 기존 HTML의 내용을 유지함
- 이미지 교체 시 기존 저작권·안내 문구를 임의로 변경하지 않음
